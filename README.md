# PDA-226: AI-Powered Movie Dialogue and Image Generation App

This is a Python desktop application developed for our SE226 course. The app allows the user to select a movie from the IMDb Top 10 list and uses AI-based tools to generate a dialogue and scene image based on the selected film. The project integrates **Tkinter**, **Gemini API**, **Vertex AI**, **BeautifulSoup**, and **IMDbPy**.

---

## Features

- Movie selection from IMDb Top 10 list
- Fetching movie summary and storyline
- Collecting character count and dialogue length input from user
- Generating custom dialogue and atmosphere using **Gemini API**
- Generating scene image based on description using **Vertex AI**
- Saving the generated dialogue to a `.txt` file
- Displaying the image and dialogue in the GUI
